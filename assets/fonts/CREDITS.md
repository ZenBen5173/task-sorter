# Font credits

| File | Family | Designer |
|---|---|---|
| `fredoka-variable.woff2` | Fredoka | Milena Brandao, Hafontia |
| `press-start-2p-400.woff2` | Press Start 2P | CodeMan38 |

Both are the **latin subset only**, taken from Google Fonts unmodified.
Fredoka is the variable font, so one file covers weights 400 to 700.

**Licence: SIL Open Font Licence 1.1** — <https://openfontlicense.org/>

The OFL permits use, study, modification and redistribution, bundled with
software, commercially, free of charge. Its one real condition is that the
fonts are not sold on their own, which is not something a game does.

- Fredoka — <https://fonts.google.com/specimen/Fredoka>
- Press Start 2P — <https://fonts.google.com/specimen/Press+Start+2P>

## Why they are here rather than fetched

The game is a mobile game. It is demonstrated on whatever wifi is in the
room and packaged into an app that has no reason to need a network. A
font that arrives over the internet is typography that only works when
the internet does.
