# Sprite credits

## Shields and swords

| File | Item in game |
|---|---|
| `wood-shield.png` | Wood Shield |
| `silver-shield.png` | Silver Shield |
| `gold-shield.png` | Gold Shield |
| `diamond-shield.png` | Diamond Shield |
| `diamond-gold-shield.png` | Diamond and Gold Shield |
| `dagger.png` | Dagger |
| `longsword.png` | Longsword |
| `gold-sword.png` | Gold Sword |
| `bronze-blade.png` | Bronze Blade |
| `winged-blade.png` | Winged Blade |

All ten are single 16x16 tiles cut out of the **Roguelike Characters**
pack by **Kenney** (<https://kenney.nl/assets/roguelike-characters>),
trimmed of their transparent margin and otherwise unedited.

**Licence: CC0 1.0 Universal** (public domain dedication) —
<https://creativecommons.org/publicdomain/zero/1.0/>

Free for personal, educational and commercial use. Attribution is **not**
required; Kenney is credited here anyway because the work deserves it and
because a public repo should always say where its art came from.

The pack's own `License.txt` is the authority on this and ships with the
download.

## Everything else

The rest of the game's pixel art is drawn in code, as colour grids in
`js/sprites.js`. The pets are separate sheets — see
`assets/pets/CREDITS.md`.
